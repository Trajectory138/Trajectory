# Goal Calendar

A minimal Next.js goal calendar product built with TypeScript and Tailwind CSS.

## Pages

- Dashboard: `/`
- Goals: `/goals`
- Goal detail: `/goals/[goalId]`
- Weekly plan: `/weekly-plan`

## Run locally

```bash
npm install
npm run dev
```

The app uses mock data in `lib/goals.ts` and does not include authentication yet.
